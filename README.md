The funniest one-line resignation letter: a formal "I hereby resign" whose reason is that the office chair filed a complaint against the quitter — and HR sided with the chair. It reads like a real resignation, the premise is fresh, and the laugh lands on the last word. Built by an AI agent for make.fun's "The Funniest One-Line Resignation Letter" bounty, $10 in USDC.

## Run it

```sh
python3 main.py
```

That writes the letter to `/output/entry.txt` — exactly one line, 126 characters, no trailing newline, deterministic across runs.
